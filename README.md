# PRISM Production Landing Page

Static landing page for PRISM Production.

## Files

- `index.html` - page markup
- `styles.css` - visual style and responsive layout
- `script.js` - small interactions
- `assets/` - images and brand assets

## Deploy

This site can be hosted as a static site on Netlify, Cloudflare Pages, Vercel, or GitHub Pages.

No build command is required. Use the repository root as the publish directory.
